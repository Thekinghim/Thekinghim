REPLAY — riktiga launches

Hitta runnern innan flocken — på pump.fun

Varje ny launch, i samma sekund den sker, via PumpPortals gratisström. Verktyget läser tre saker som pump.fun självt inte visar dig: deployerns meritlista, hur mycket av supplyn deployern tog i öppningsblocket, och om uppmärksamheten kom före eller efter de riktiga köparna.

REPLAY Mynten nedan är riktiga pump.fun-launches — riktiga mintadresser du kan slå upp, från ett godtyckligt 81-minutersfönster den 19 januari 2025. Ingen selektion på utfall: 27 av 32 blev high-risk, vilket är hur flödet faktiskt ser ut. Utfallen kommer från MELT (Georgia Tech, 26 996 märkta launches). Ingen köprekommendation ges i replay: tre av fyra signaler kräver live-strömmen, och socials ensamt separerar inte utfall. Tryck "visa utfall" för att se vad som hände.

Vad verktyget kan och inte kan

Kan: se varje launch i samma sekund, gratis och utan API-nyckel (wss://pumpportal.fun/api/data), och bygga en creator-historik som växer för varje dygn det körs.

Kan inte: förutsäga vilken coin som pumpar. Av de 200 största avkastningarna i datasetet var 86 klassade som högrisk — runners är ofta högrisk, så ett rent riskfilter hade sållat bort 43 % av de största vinnarna. Medianen är −66 % och bara 20 % av alla launches slutar plus.

Creator-historiken är det som inte går att köpa. MELT:s publika dataset har inget användbart creator-fält — det är en och samma adress på alla 46 139 rader. Ingen datatjänst säljer den heller. Den finns bara om man spelar in strömmen själv, från dag ett.

Kör det

npm run scout — live mot pump.fun via PumpPortal
npm run replay — den här vyn, mot inspelade launches
python packages/research/melt_repro/verify_baseline.py — reproducerar baslinjen

Verktyget lägger inga ordrar. Memecoin-handel är negativ-summa efter avgifter för de flesta deltagare. MELT-datan är CC BY-NC 4.0 — den får användas för forskning och validering, inte i en såld produkt utan tillstånd från författarna.
